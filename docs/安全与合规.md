# 安全与合规

## 基本原则

- 只在你拥有或被授权操作的抖音账号上使用本程序。
- 使用频率、内容和目标会话应符合抖音平台规则和对方预期。
- 程序不会绕过登录、验证码、风控、扫码或账号安全验证。
- 仿人节奏只用于形成自然、低频的本地操作过程，不保证规避平台限制；出现安全提示时程序会暂停并等待人工处理。
- 程序不会主动上传你的配置、日志、截图或浏览器登录态。

## 本地敏感数据

默认数据目录为 `%APPDATA%\DouyinAutoSpark`，其中可能包含敏感信息：

| 内容 | 风险 |
| --- | --- |
| `browser-profile` | 包含专用 Chromium 登录态。 |
| `config.json` | 包含目标会话关键词和发送内容。 |
| `logs` | 可能包含目标昵称、错误信息和本机路径。 |
| `screenshots` | 可能包含私信页面截图。 |
| 离线页面快照 | 可能包含昵称、头像、消息内容或页面标识。 |

不要把以上内容提交到 GitHub、发送给陌生人或打包到公开发布包中。

## 上传 GitHub 前的隐私检查

上传前建议检查：

1. `.gitignore` 是否排除了 `target`、`build`、`PLUGIN`、日志、截图、浏览器资料目录和本地临时文件。
2. 离线测试页面是否已经脱敏，只保留选择器测试所需结构。
3. 文档中是否包含真实账号、手机号、二维码、Cookie、Token 或个人路径。
4. Release 压缩包是否只包含程序运行所需文件，不包含本机数据目录。

## 账号安全建议

- 首次登录时确认地址为抖音创作者中心官方页面。
- 不要把登录态目录复制到其他电脑或分享给他人。
- 如果怀疑登录态泄露，请立即在抖音账号安全设置中退出相关登录设备。
- 自动发送内容尽量简短自然，不要用于骚扰、刷屏、营销或绕过平台限制。

## 漏洞反馈

如果发现安全问题，请通过 GitHub Issues 反馈。提交时不要附带真实 Cookie、Token、二维码、私信截图或其他敏感信息；如必须说明，请先做脱敏处理。
