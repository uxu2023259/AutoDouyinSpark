# 使用说明

本文面向普通使用者，说明如何安装、登录、配置和排查抖音自动续火花助手。

## 一、下载与解压

1. 从 GitHub Releases 下载 `douyin-auto-spark-*-windows.zip`。
2. 右键压缩包，选择“全部解压”或使用解压软件完整解压。
3. 解压后应能看到 `抖音自动续火花助手.exe`、`启动诊断.cmd`、`使用说明.txt`、`app`、`runtime`、`browsers` 等内容。
4. 不要只复制 `.exe`，也不要直接在压缩包里双击运行。

## 二、首次启动与登录

1. 双击 `抖音自动续火花助手.exe`。
2. 如果没有窗口，请双击 `启动诊断.cmd` 查看中文诊断提示。
3. 点击“打开登录/聊天页”。
4. 在弹出的内置 Chromium 浏览器中完成抖音创作者中心登录。
5. 登录成功后保持浏览器窗口可用，程序会复用本次登录状态。

程序不会绕过扫码、验证码、风控或任何账号安全校验。登录失效时，请重新点击“打开登录/聊天页”并手动完成验证。

## 三、配置项说明

| 配置项 | 说明 | 建议值 |
| --- | --- | --- |
| 启用状态 | 是否允许自动调度执行。 | 启用 |
| 巡检间隔（分钟） | 间隔多久检查一次目标会话。 | 30 |
| 固定触发时间（HH:mm） | 每天到指定时间额外触发一次；留空表示关闭。 | 16:00 |
| 目标会话关键词 | 每行一个会话名称或关键词。 | 使用唯一、稳定的昵称关键词 |
| 发送内容 | 要发送到目标会话的文字。 | 简短自然的中文消息 |
| 每日最大发送次数 | 每天最多计入多少次确认成功发送。 | 20 以内 |
| 每个用户冷却时间（分钟） | 同一目标两次成功发送之间的最短间隔。 | 60 或更长 |
| 失败重试次数 | 单个目标失败后的额外重试次数。 | 2 |
| 启动方式 | 是否为当前 Windows 用户安装开机自启守护。 | 按需开启 |

填写完成后点击“保存配置”。需要验证时点击“立即执行一次”。

## 四、目标会话匹配策略

当前稳定策略如下：

- 会先从左侧会话列表中提取当前可见会话。
- 目标匹配顺序为完全匹配、包含匹配。
- 如果存在多个同名或相似结果，不再强制报错。
- 多结果时优先使用当前选中的会话；如果没有唯一选中项，则使用第一个匹配项。
- 切换会话后的标题检测只用于日志和排错，不作为强阻断条件。
- 发送时优先点击“发送”按钮，必要时补发 Enter 键。
- 如果发送动作已触发但短时间内不能确认清空输入框，会记录为“结果不确定”，不计入成功次数。

## 五、运行状态与数据目录

默认数据目录为 `%APPDATA%\DouyinAutoSpark`。

| 内容 | 路径 |
| --- | --- |
| 配置文件 | `%APPDATA%\DouyinAutoSpark\config.json` |
| 状态文件 | `%APPDATA%\DouyinAutoSpark\state.json` |
| 登录态目录 | `%APPDATA%\DouyinAutoSpark\browser-profile` |
| 日志目录 | `%APPDATA%\DouyinAutoSpark\logs` |
| 失败截图目录 | `%APPDATA%\DouyinAutoSpark\screenshots` |

如需重新登录，可以关闭程序和浏览器后，删除 `browser-profile` 目录，再重新启动并登录。

## 六、日常使用建议

- 尽量保持 Windows 已登录并处于可交互桌面会话。
- 不要频繁发送重复内容，建议设置合理冷却时间和每日上限。
- 如果抖音页面提示安全验证，请先手动完成验证。
- 如果页面结构变化导致失败，请保留日志和失败截图用于排查。
- 修改配置后建议点击“立即执行一次”确认目标会话能正确命中。
