# 常见问题

## 双击后没有窗口怎么办？

请双击同目录下的 `启动诊断.cmd`。诊断脚本会检查启动入口、主程序、内置浏览器目录和日志位置，并输出中文提示。

## 提示找不到内置 Chromium 浏览器怎么办？

通常是压缩包没有完整解压，或只复制了单个启动入口。请重新完整解压整个 `抖音自动续火花助手` 文件夹，确认 `browsers` 目录存在。

## 为什么程序不在锁屏或无人登录时启动浏览器？

手动登录窗口需要可交互的 Windows 桌面会话。每日自动任务默认使用无界面 Chromium，不需要显示浏览器窗口；首次登录、验证码和安全验证仍需点击“打开登录/聊天页”并在可交互桌面中手动完成。

## Chromium 启动后立即退出，日志出现 exitCode=21 怎么办？

这通常表示同一账号的 `browser-profile` 正被另一个助手实例或遗留 Chromium 进程占用。

1. 查看任务栏和任务管理器，确认没有另一个“抖音自动续火花助手”正在运行。
2. 关闭旧版助手，以及命令行中包含当前账号 `browser-profile` 路径的 Chromium 进程。
3. 再启动新版程序；新版具备全局单实例锁和账号资料目录占用检查，会直接给出中文提示。
4. 不要同时从两个解压目录运行助手，因为它们仍会共用 `%APPDATA%\DouyinAutoSpark` 数据目录。
5. 只有确认所有相关程序均已关闭后，才考虑备份并重置该账号的 `browser-profile`。

## 登录失效怎么办？

点击“打开登录/聊天页”，在内置 Chromium 中重新扫码或完成验证。登录成功后保持程序运行至少 15 秒，日志出现“已将当前抖音登录会话写入持久化浏览器资料”即表示本次持久化完成。程序不会绕过验证码、风控或任何登录校验；抖音主动注销、账号安全策略或服务端令牌失效时仍需重新验证。

## 为什么显示“结果不确定”？

程序已经触发发送，但没有确认到一条发送前不存在、文本一致且状态正常的己方新消息气泡。输入框清空和接口响应不能单独判定成功。此时会把该用户记为“结果不确定”，当天不会自动重发，以避免重复消息；下一天再按日计划处理。

## 为什么浏览器正常但日志出现页面操作异常？

页面虚拟列表重绘、元素暂时不可见或业务检测超时不等于浏览器连接断开。单次名单处理中会保留当前浏览器和聊天标签页，并按发送动作是否已经触发分别记录为普通失败或结果不确定。每日任务结束或暂停后会关闭自动化浏览器以释放内存，登录资料会保留；只有页面、浏览器上下文或 Playwright 控制连接在处理过程中明确关闭时才提前重建浏览器。手动打开的登录窗口会保持可用。

新版不会要求 Chromium 恢复上次会话。启动时如发现多个相同聊天页，会复用其中一个并清理其余重复聊天页；非聊天标签页不会关闭。程序也不会在已有聊天页可用时再次打开新聊天页。

## 如何减少浏览器内存和 CPU 占用？

自动发送默认使用无界面 Chromium，并在名单处理完成或暂停后关闭浏览器；下一次计划任务开始时才按需启动。手动打开登录窗口后浏览器会保持运行，关闭该窗口即可释放这部分资源。每个账号的登录资料保存在独立目录，关闭浏览器不会清除登录状态。运行维护中的无界面选项关闭时，浏览器只会在发送期间显示，任务结束后仍会关闭。

## 为什么页面一直显示加载中？

新版会最多等待 45 秒识别会话列表或登录提示。仍未就绪时，本次目标会记录失败并保留当前页面；不会重试该用户，也不会因元素暂时缺失而反复刷新。名单中的其他用户仍会逐一处理，未成功的用户次日再按计划处理。

- 请检查服务器网络和抖音创作者中心是否可访问。
- 首次加载、登录跳转或服务器资源紧张时可能需要更长时间。
- 只有浏览器进程或控制连接真正失效时，程序才会重建浏览器。
- 页面结构暂时未识别时不会再次尝试当前用户，避免重复发送或形成刷新循环。

## 目标会话没有命中怎么办？

请确认完整用户名与左侧会话列表中的名称一致，并确认该用户不是多个同名会话之一。程序只按完整名称匹配，不会使用包含匹配；当天失败后不会立刻重试，请检查日志并等待下一天。

## 多个会话名称相似怎么办？

相似但不完全同名的会话不会命中。如果列表中有多个完全同名会话，程序会标记“重名”并跳过，不会任选一个发送。请先在抖音中区分这些联系人；当前名单只接受名称唯一的用户。

## 为什么发送一个用户后显示已处理？

“已处理”表示程序已经为这些用户分别记录了结果，不代表全部发送成功。顶部会分别显示“今日确认”和“已处理”的数量；实时日志会列出每位用户的结果。只有名单中每位用户都确认成功时，日志才会显示“今日名单全部发送成功”。

## 更新后提示旧版发送记录无法对应用户怎么办？

旧版本可能只保存了会话标识，无法安全地对应到具体用户名。程序会在升级当天暂停剩余名单，防止重复发送；次日会按新规则正常开始。

## 日志和截图在哪里？

默认在 `%APPDATA%\DouyinAutoSpark`：

- 日志：`logs`
- 账号注册表：`accounts.json`
- 失败截图：`accounts\账号ID\screenshots`
- 配置：`accounts\账号ID\config.json`
- 状态：`accounts\账号ID\state.json`
- 登录态：`accounts\账号ID\browser-profile`

## 如何重新开始配置？

建议在工作台中新建账号或归档旧账号。确需重置时，先关闭程序和相关 Chromium，再备份并处理 `%APPDATA%\DouyinAutoSpark\accounts\账号ID`；不要误删其他账号目录。

## 杀毒软件误报怎么办？

发布包由项目构建脚本生成，包含 Java 运行时、Chromium 和自动化依赖，体积较大，个别安全软件可能提示风险。请只从本仓库的可信 Release 下载，并自行决定是否加入信任列表。
