# 常见问题

## 双击后没有窗口怎么办？

请双击同目录下的 `启动诊断.cmd`。诊断脚本会检查启动入口、主程序、内置浏览器目录和日志位置，并输出中文提示。

## 提示找不到内置 Chromium 浏览器怎么办？

通常是压缩包没有完整解压，或只复制了单个启动入口。请重新完整解压整个 `抖音自动续火花助手` 文件夹，确认 `browsers` 目录存在。

## 为什么程序不在锁屏或无人登录时启动浏览器？

程序需要可交互的 Windows 桌面会话来显示浏览器窗口。未检测到可交互桌面会话时，程序只记录等待状态，不启动浏览器。

## 登录失效怎么办？

点击“打开登录/聊天页”，在内置 Chromium 中重新扫码或完成验证。程序不会绕过验证码、风控或任何登录校验。

## 为什么显示“结果不确定”？

程序已经尝试触发发送动作，但短时间内没有确认输入框清空。为了避免误计数，这种情况不会计入成功次数。请查看日志和失败截图确认实际页面状态。

## 目标会话没有命中怎么办？

建议使用更唯一的会话关键词，并先确认目标会话出现在左侧可见会话列表中。修改后点击“立即执行一次”验证。

## 多个会话名称相似怎么办？

程序会优先使用当前选中的会话；如果没有唯一选中项，则使用第一个匹配项。建议使用更精确的关键词减少误命中。

## 日志和截图在哪里？

默认在 `%APPDATA%\DouyinAutoSpark`：

- 日志：`logs`
- 失败截图：`screenshots`
- 配置：`config.json`
- 状态：`state.json`

## 如何重新开始配置？

关闭程序和浏览器后，可以删除 `%APPDATA%\DouyinAutoSpark\config.json` 和 `state.json`。如需重新登录，再删除 `browser-profile` 目录。

## 杀毒软件误报怎么办？

发布包由本地 `jpackage` 生成，包含 Java 运行时、Chromium 和自动化依赖，体积较大，个别安全软件可能提示风险。请只从可信 Release 下载，并自行决定是否加入信任列表。
